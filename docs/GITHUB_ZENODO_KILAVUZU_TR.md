# Yeni Zenodo DOI'sini GitHub'da gösterme

**Sürüm DOI:** https://doi.org/10.5281/zenodo.23311944  
**GitHub:** https://github.com/serbestziyanak/explainable-credit-default-prediction

Bu DOI kullanıcı tarafından yeni arşiv için bildirilmiştir. Zenodo kaydındaki içerik ile GitHub'ın `v2.0.0` sürümü eşleşiyor mu kontrol edin.

## GitHub'da güncelleme

1. Bu paketteki `README.md` ve `CITATION.cff` dosyalarını GitHub deposunun **ana dizinine** yükleyip mevcut dosyaları değiştirin.
2. `SHA256SUMS.txt` dosyasını da birlikte güncelleyin; aksi hâlde kod paketinin dosya doğrulama özetleri eski README ve CFF için yanlış olur.
3. Bu rehberi `docs/GITHUB_ZENODO_KILAVUZU_TR.md` olarak güncelleyin.
4. Değişiklikleri commit edin. Yeniden DOI almaya gerek yoktur; ancak bu yeni commit, önceden yayımlanmış Zenodo snapshot'ının içeriğini otomatik olarak değiştirmez.

## Makale atıf cümlesi

**Türkçe:** Çalışmaya ait kodlar ve PAPER modu deney sonuçları GitHub deposunda (https://github.com/serbestziyanak/explainable-credit-default-prediction) sunulmuş ve Zenodo'da sürüme özgü DOI (https://doi.org/10.5281/zenodo.23311944) ile arşivlenmiştir.

**English:** The analysis code and PAPER-mode experimental output archives are available in the GitHub repository (https://github.com/serbestziyanak/explainable-credit-default-prediction) and are archived on Zenodo under the version-specific DOI https://doi.org/10.5281/zenodo.23311944.

## Önemli not

Zenodo DOI'si kullanıcı tarafından sağlanmıştır; metadata ve arşiv içeriği otomatik olarak bağımsız şekilde doğrulanamamıştır. Zenodo'nun kaydı açıldığında yayın türünü, yazarları, sürümü ve mevcut dosyaları ayrıca kontrol edin. Bu kontrol, atıf künyesini kesinleştirmek için önemlidir.
